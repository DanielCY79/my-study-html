MCP 委派，加上事件驱动

T3 Code 偏向统一运行协议与状态管理。核心是三件事：把协作包成工具调用、用事件把状态留下、把应用会话和原生会话分开交接。

Orchestrator V2：事件留下，执行分开

Context Handoff：应用会话和原生会话分开

仍然共享不了。不同 Agent 内部的推理状态和 KV Cache 还是各管各的。交接补的是对话历史，不是把缓存合到一起。
