差异、趋同，与 Agent 的操作系统

前两页分别是 T3 Code 和 Orca。这一页是差异对照，以及操作系统映射。

  1. 05差异与趋同
  2. 06Agent 的操作系统

05

发力点不同，能力在靠拢

T3 Code 侧重统一运行协议、会话管理、上下文交接和事件流。Orca 侧重任务依赖、派工隔离、结构化通信和 Worker 生命周期。两边的能力也在互相靠拢。

T3 Code 侧重

  • 统一 Agent 运行协议
  • 会话管理
  • 上下文交接
  • 事件流

Orca 侧重

  • 任务依赖
  • 派工隔离
  • 结构化通信
  • Worker 生命周期

已经互相补上的部分

  • T3 补上已有实验性的 TypeScript Workflow。
  • Orca 补上补上了跨 Agent 会话交接。
  • 两边都有都用 Git Worktree 隔离并行任务，减少多个 Agent 同时改代码带来的冲突。

06

越来越像面向 Agent 的操作系统

套用操作系统的视角，这套编排架构的每一层几乎都能一一对应。

多 Agent 编排真正有门槛的，从来不是并发数量，而是底层的分工、通信、等待、交接与容错，最终把分散的结果拼成一个可交付的项目。这些基础设施补齐之后，Coding Agent 管理工具就越来越像一套专门面向 Agent 的操作系统。
